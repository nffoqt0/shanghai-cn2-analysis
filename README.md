## 一、先把「上海 CN2」这件事说清楚：不是出口产品，是国内优化

MKCloud 的上海 CN2 在官方知识库里归类为「国内优化产品」，与它家其他沪港、沪日、沪美、厦港、IXP 上云这几类跨境专线是两套逻辑。

核心三条线：

- **入口**：上海动态联通（不是上海 8 线 BGP，也不是任意一家云厂商接入）。
- **出口**：上海电信 CN2（注意：官方资料里只写「上海电信 CN2 出口」，未宣布全程 CN2 GIA）。
- **IP**：动态 IPv4，每台 VPS 分配 1 个独立入口 IP + 1 个独立出口 IP。**变化周期和触发条件不公开**，白名单和固定出口用户不应自行假设它的稳定性。

这款产品的可交付形态有云服务器和独立物理服务器两种，所有配置可以定制；起步价在 MKCloud 首页写的是 **¥4500.00/月起**。

需要明确的是：

- 它**不能当香港、日本、美国出口使用**——出口就是上海。如果你业务明明要出海，应该去看沪港、沪日、沪美。
- 它**也不等于 CN2 GIA**——官方资料里没有提供足以证明全程 GIA 的文档。CN2 全程（GIA）有强需求的人，应在下单前拿到对应的网络说明，不能默认它就是 GIA。

> 这点在 MKCloud 知识库《上海 CN2 动态 IP 产品说明》里写得很直接：「需要海外地区出口的用户，应另看沪港、沪日或沪美产品。它不是香港、日本或美国出口，也不能仅凭 CN2 名称认定全程属于 CN2 GIA。」

## 二、上海 CN2 适合谁、不适合谁

在判断要不要上这款产品之前，先看 MKCloud 自己划出的边界。

### 适合的情况

- 你需要上海国内入口 + 上海电信 CN2 出站组合，对「动态 IP」能接受，本身业务确实只在国内访问链路上做回环。
- 你的业务对动态出口 IP 没有强白名单依赖——比如测试、采集、本地到出站通道验证、账号编排等场景。
- 你需要一台拥有独立入口和出口 IP、且能直接拿到物理机资源或云服务器的合规节点。

### 不适合的情况

- 需要固定 IP 做白名单、长期保持同一出口地址的——动态 IP 的具体规则不公开。
- 需要香港、日本、美国出口走海外业务——上海 CN2 不是海外出口产品。
- 期待「晚高峰零拥堵、最高优先级」——MKCloud 在 FAQ 里已说明「不能以 CN2 名称推定最高优先级或晚高峰零拥堵」。
- 想拿它当原生 IP / 住宅 IP / 流媒体解锁 / 账号防封工具——这些都不是已承诺能力，原生 IP 和住宅 IP 相关项目应另寻方案。
- 合规红线之外用途：MKCloud 在产品页明确写明「仅限个人或企业正规用途使用，禁止机场、回国等违法违规用途」，一线岗位自审。

## 六、购买前还要确认的几个硬限制

MKCloud 在多个产品页都写得比较严格，下单前先把这些条款对清楚：

1. **实名制 + 中国身份信息**：所有产品都需要实名认证。仅限个人或企业正规用途，禁止机场、回国等合规违规用途，一经发现立刻清退不退款。
2. **退款政策**：仅支持质量问题退款，且需提交准确延迟 / 速度等数据。**服务开通后不支持更换到其他地域产品**。这意味着选错线路不能换货，下单前必须确认入口、出口、计费方式。
3. **升降级**：套餐升降级都需提交工单；**降至更低价格套餐时差价不退**，是否迁移以工单处理结果为准。
4. **共享带宽 ≠ 持续跑满**：流量计费套餐按上行、下行双向统计；超过额度会暂停，可买流量重置或工单补差价升级。共享 200Mbps 峰值和独享 5Mbps 不是同一资源池，不能直接比。
5. **上海 CN2 的 IP 规则**：动态 IPv4 不可白名单预设，变化周期不公开，固定出口 / 长期白名单业务不应依据未公开规则采购。
6. **支付方式**：现阶段仅支持支付宝，更多支付方式敬请期待。

如果你只是需要一台上海本地出站、合规、双线冗余的节点，且对动态 IP 接受度高，上海 CN2 是一款与官方定价高度匹配的产品；但如果你需要「大带宽 + 固定 IP + 海外出口 + 长期稳定白名单」，应该回到 沪港 IPLC / 沪日 IPLC / 沪美 IPLC / 广港 IEPL 这几条主线按需选择——它们比上海 CN2 便宜得多，也更成熟。

## 七、常见问题

### 上海 CN2 是 CN2 GIA 吗？

公开资料显示只有「上海电信 CN2 出口」，没有足以证明全程 CN2 GIA 的材料。如果你采购硬要求是 GIA，下单前应明确拿到对应说明，不能默认。

### 动态 IP 会比固定 IP 更安全吗？

动态 IP 与账号安全没有直接因果关系。MKCloud 知识库明确说明「动态 IP 不保证规避风控或提高账号安全」，频繁变化的登录环境反而可能增加额外验证。具体效果由平台规则和账户行为决定。

### 上海 CN2 能当成香港 / 美国节点用吗？

不能。它的入口和出口都在上海，只是国内 CN2 出站。海外出口请选沪港、沪日、沪美或广港 IEPL。

### 上海 CN2 的运行速度怎么测？

MKCloud 官方建议：「测试本地到入口，以及 VPS 到实际目标的连接和传输」，**不以 CN2 名称推定最高优先级或晚高峰零拥堵**。建议按真实业务目标 + 高峰 / 低谷时段分别测试。

### 跑不满带宽怎么办？

带宽跑不满可能来自本地网络、协议、目标限速、服务器配置、网络拥堵等因素。可以提交工单让 MKCloud 工程师协助，但工程师能解决的只在公共边界以内，第三方目标限速不属于 MKCloud 服务范围。

### 买完不适合能不能退？

仅质量问题退款，且不支持换地域。下单前一定要确认出口方向、计费类型、IP 类型（动态 vs 固定）、计费周期和配件省份。
